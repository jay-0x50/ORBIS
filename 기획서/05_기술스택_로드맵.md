# 프로젝트 오르비스 — 기획서 5부: 기술 스택 & 개발 로드맵

## 1. 기술 스택

| 영역 | 사용 기술 |
|---|---|
| 엔진 | Unity 6 (URP) |
| 카메라 | Cinemachine |
| 입력 | Unity Input System |
| 애니메이션 | Animator + 커스텀 FSM(캐릭터 전투 상태머신) |
| 이펙트 | VFX Graph, Shader Graph |
| 월드 스트리밍 | Addressables (지역별 씬 분할 로딩) |
| 세이브 | JSON 직렬화 기반 자체 세이브 시스템 |
| 버전 관리 | Git |

## 2. 핵심 아키텍처 개요

- **캐릭터 상태머신**: Idle / Move / Attack / Skill / Burst / Hurt / Dead — 공통 FSM 베이스 클래스에서 캐릭터별 상속
- **원소 반응 매니저**: 싱글톤 + 이벤트 버스 구조. 원소 부착 시 이벤트 발행 → 매니저가 조합 판정 후 이펙트·데미지 처리
- **오브젝트 풀 매니저**: 파티클, 데미지 넘버, 투사체 전용 풀링 (성능 핵심)
- **파티 매니저**: 4인 파티 상태 관리, 스위칭 처리, 필드 잔여 원소 타이머 관리

## 3. 개발 로드맵 (마일스톤)

| 단계 | 목표 | 핵심 산출물 |
|---|---|---|
| M0. 코어 프로토타입 | 이동+카메라+캐릭터 1인 기본전투 | 걷기/달리기/점프/기본공격 |
| M1. 파티 시스템 | 4인 스위칭 + 원소 부착/반응 기초 | 원소 반응 매니저 동작 확인 |
| M2. 오픈월드 탐사 | 등반/활공/수영 + 지역 1곳 프로토타입 | 필드 퍼즐 1종, 도전의 방 1종 |
| M3. 이펙트 폴리싱 | 궁극기 연출, 히트감 3요소 적용 | VFX Graph 기반 스킬 이펙트 완성 |
| M4. 콘텐츠 확장 | 나머지 4개 지역, 필드보스, 일일퀘스트 | 오픈월드 콘텐츠 1차 완성 |

## 4. 협업 노트

- 본 기획서(1~5부)는 세계관·오픈월드·전투·애셋·로드맵을 아스트라(개발 총괄)에게 전달하기 위한 기준 문서
- 코덱스가 실제 코드를 짤 때는 M0부터 순서대로 구현 → 뼈대 완성 후 M3(이펙트)에 리소스 집중 투입 권장
- 기획 변경/확장 시 본 문서 세트를 기준본으로 갱신
