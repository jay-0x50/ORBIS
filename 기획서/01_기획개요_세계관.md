# 프로젝트 오르비스 (Project Orbis) — 기획서 1부: 개요 & 세계관

## 0. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 장르 | 오픈월드 원소 액션 RPG |
| 엔진 | Unity (URP, Unity 6 기준) |
| 플랫폼 | PC 우선 → 추후 모바일 이식 고려 |
| 시점 | 3인칭 액션 |
| 한줄 컨셉 | 5원소가 살아 숨쉬는 대륙 오르비스를 탐험하며, 파티원을 자유롭게 전환해 화려한 원소 콤보로 전투하는 오픈월드 액션 RPG |
| 개발 구조 | 기획(본 문서 세트, Claude) → 개발 총괄/설계(아스트라) → 코드 구현(코덱스) |

### 핵심 재미 축 (Design Pillars)
1. **자유로운 탐사** — 등반, 활공, 수영으로 막힘 없이 이동하는 오픈월드
2. **원소 콤보 전투** — 4인 파티 실시간 스위칭 + 원소 반응으로 만드는 전략적 액션
3. **보는 맛 있는 이펙트** — 궁극기/원소 반응마다 화면을 채우는 화려한 VFX
4. **수집 & 성장** — 캐릭터·무기를 모으고 키우는 장기 리텐션 루프

### IP / 라이선스 원칙 (반드시 지킬 것)
- 오픈월드 + 원소 스위칭 + 파티전투라는 **장르 문법**은 원신 등 기존 오픈월드 원소 ARPG를 벤치마킹한다.
- 세계관, 지명, 캐릭터명, 비주얼 디자인, 3D 모델, 음악 등 **모든 표현 요소는 오리지널이거나 라이선스가 명확한 오픈소스/무료 애셋만 사용**한다.
- 특정 상용 게임의 캐릭터·로고·텍스트·모델 파일을 추출해 쓰는 행위는 금지 (저작권 침해).

## 1. 세계관: 오르비스

### 한 줄 설정
대륙 오르비스는 5개 원소의 힘이 응축된 유적 "원환(原環)"들로 뒤덮여 있다. 플레이어는 이 힘을 다루는 "탐구자"가 되어 대륙을 가로지르며, 각 지역에 잠든 원소 수호자들을 깨워 동료로 맞이한다.

### 메인 스토리 후크
대륙 중심부의 "원초의 균열"이 다시 열리며 5원소의 균형이 무너지기 시작했다. 각 지역은 이상 현상(폭주하는 원소 몬스터, 뒤바뀐 날씨)을 겪고 있으며, 탐구자는 지역 수호자와 협력해 균형을 되찾아야 한다.
→ 세부 메인 퀘스트 시나리오는 별도 시나리오 문서에서 확장 필요.

### 5개 지역 개요

| 지역명 | 원소 | 지형 | 상징 세력 | 필드 몬스터 (확정 3종) |
|---|---|---|---|---|
| 아그니아 고원 | 화(火) | 활화산, 용암 협곡 | 대장장이 부족 | 화염정령, 마그마쥐, 잿불도마뱀 |
| 텔루나 군도 | 수(水) | 다도해, 산호 동굴 | 항해자 연합 | 물방울정령, 심해괴수, 산호도치 |
| 자피르 초원 | 풍(風) | 광활한 평원, 거대 풍차 | 유목 부족 | 바람매, 선회정령, 돌개늑대 |
| 그라니테 산맥 | 암(岩) | 고산 광산지대 | 채굴 길드 | 크리스탈 게, 암석거인, 광맥두더지 |
| 볼트하임 | 뢰(雷) | 뇌운 첨탑도시 | 기술 문명 | 전기해파리, 스파크골렘, 번개박쥐 |

*(지명·세력명은 초안이며, 본개발 전 브랜딩 재검토 권장. 필드 몬스터는 컨셉아트 확보 완료로 명칭 확정 — 상세 스펙·보스·원소 슬라임·무속성 공용 적은 `09_필드몬스터_보스_도감.md` 참고)*

## 2. 핵심 게임 루프

```
탐사(필드 이동/퍼즐) → 전투/채집으로 자원 획득 → 캐릭터·무기 강화 → 새 지역 개방 → 반복
```

- **단기 루프(세션당)**: 필드 탐사 → 미니 던전 클리어 → 강화 재료 획득
- **중기 루프(일/주간)**: 일일 위임 퀘스트, 주간 챌린지 던전, 필드 보스 리젠
- **장기 루프**: 신규 캐릭터·지역 해금 → 최종 컨텐츠(고난도 도전의 방) 갱신

## 3. 캐릭터 컨셉 (초기 5종 예시)

| 이름(가칭) | 원소 | 무기 | 역할 |
|---|---|---|---|
| 이그니스 | 화 | 장검 | 근접 딜러 |
| 마리스 | 수 | 활 | 원거리 힐/서포터 |
| 아우라 | 풍 | 쌍검 | 스피드 서브딜러 |
| 그롬 | 암 | 대검 | 탱커 |
| 스파클 | 뢰 | 창 | 버스트 딜러 |

각 캐릭터는 기본공격 / 원소 스킬 / 원소 폭발(궁극기) 3종 슬롯을 가진다. 상세 설계는 `03_전투_스킬이펙트설계.md` 참고.

> 뽑기 시스템 도입에 따라 위 5인은 **5성 캐릭터**로 승격되며, 전체 로스터(스타터 3 + 4성 10 + 5성 5, 총 18인)는 `06_재화_뽑기_동료풀.md` 참고.

> 플레이어가 직접 조작하는 주인공(탐구자, 남녀 선택형)과 동행 조력자 캐릭터는 가챠 로스터와 별개이며, 비주얼 레퍼런스는 `07_주인공_조력자.md` 참고.

## 4. 비주얼 아이덴티티 (컨셉아트 반영)

확보된 주인공/조력자 컨셉아트와 뽑기 UI 목업을 통해 아래 비주얼 방향이 사실상 확정되었다.

### 공식 태그라인
- 국문: "별이 이끄는, 새로운 여정" / "세계는 이어져도, 언젠가 당신과."
- 영문: "More Stars, Another Tomorrow." / "A World Beyond the Skies."
- 보조 카피: "세상의 끝에도, 아직 보지 못한 이야기가 있다." / "탐험하라. 싸워라. 발견하라. 함께하라. (Explore. Fight. Discover. Together.)"

### 핵심 모티브 — 별자리 & 나침반
- 주인공(스텔라/폴라리스), 조력자(코스모), 뽑기 시스템 UI, 그리고 각 지역의 정령·보스 몬스터 갑주·코어 장식까지 모두 "별자리·나침반" 모티브를 공유한다.
- 공통 컬러 코드: 남색(Navy) · 화이트(White) · 골드(Gold) — 원소 몬스터는 여기에 원소별 컬러(03번 문서 팔레트)가 더해지는 구조
- 이 모티브는 캐릭터 비주얼에 한정되지 않고 게임 전체의 브랜드 아이덴티티(로고, UI 프레임, 연출 이펙트, 몬스터 장식)로 확장 적용한다.
- 로고: 8방향 별/나침반 심볼 — 뽑기 화면 상단, 로딩 화면, 타이틀, 도감 UI 등에 반복 사용 권장

> 캐릭터 비주얼 상세는 `07_주인공_조력자.md`, 뽑기 UI/연출 상세는 `08_뽑기_UIUX_연출설계.md`, 필드 몬스터·보스 상세는 `09_필드몬스터_보스_도감.md`, 몬스터 컨셉아트 생성 프롬프트는 `10_몬스터_컨셉아트_프롬프트가이드.md` 참고.
