## 2. 스타일 통일 전략

여러 소스에서 가져온 애셋은 스타일이 제각각이라 아래 방식으로 통일감을 만든다.

1. **공통 툰쉐이더 강제 적용**: 모든 캐릭터·환경 머티리얼에 동일 툰쉐이더 + 아웃라인 두께 적용
2. **컬러 팔레트 통일**: 환경 텍스처는 포스트프로세싱(컬러 그레이딩)으로 톤 맞추기
3. **비율 통일**: 캐릭터 헤드-투-바디 비율을 기준치로 리스케일 (SD 캐릭터 vs 실사 비율 혼용 방지)

## 4. 월드 개선 STEP 2 — 실제 도입 기록 (2026-09-11)

### 무료 자연 에셋과 파생 데이터

| 소스 | 이번에 사용한 원본 모델 | 실제 확보 범위 / 출처 |

[공식 제품 페이지](https://quaternius.com/packs/stylizednaturemegakit.html), [제작자 다운로드 페이지](https://quaternius.itch.io/stylized-nature-megakit), [동봉 CC0 라이선스](../Docs/WorldArt/Sources/Quaternius_MegaKit_License_Standard.txt) |

MegaKit의 **무료 Standard 68개**, **유료 Pro 전체 116개**, **유료 Source 전체 모델 + Unity URP·Unreal·Godot 프로젝트/셰이더**를 구분한다. 이 숫자는 확보한 ZIP의 동봉 라이선스와 모델 목록을 기준으로 한다. 공식 페이지 일부 이미지 설명에는 다른 개수가 혼재하므로, 홍보 이미지의 수를 실제 다운로드 수로 기록하지 않는다. 이번에는 유료 Pro/Source판과 제작자의 URP 프로젝트·셰이더를 내려받거나 도입하지 않았다.

두 팩은 공식 제품 페이지와 동봉 파일에 CC0 1.0이 명시되어 있다. Ultimate 동봉 파일의 제목에는 다른 팩 이름인 `Ultimate Platformer Pack`이 남아 있어 원문을 수정하지 않고 보존했으며, **Ultimate Stylized Nature 공식 제품 페이지의 CC0 표시도 함께 확인**했다. [공식 HTML·라이선스 증빙 색인](../Docs/WorldArt/Sources/Quaternius_증빙_안내.md), [접근 시각·원본 URL·SHA-256](../Docs/WorldArt/Sources/Quaternius_License_Evidence.json)

`Tools/WorldDev/build_nature_lods.py`가 보존 원본에서 LOD0/LOD1 FBX 24개, 나무 7수종의 실제 모델을 무조명 렌더한 8방향 빌보드 7장, 반복 UV용 512² 컬러 텍스처 15장을 만든다. LOD 메시·빌보드는 해당 CC0 모델/텍스처의 파생 데이터이며 imagegen 이미지가 아니다. 원본 ZIP·FBX·PNG는 `Tools/WorldDev/SourceDownloads/`에 보존한다. [모델·텍스처 매핑 및 원본 해시](../Assets/Orbis/Game/World/Nature/NatureModelManifest.json)

### 프로젝트에서 생성한 지면 텍스처

`Assets/Orbis/Game/World/Ground/Textures/`의 `Meadow.png`, `Earth.png`, `Stone.png`, `Moss.png`는 내장 imagegen으로 만든 프로젝트용 알베도 4장이다. 생성 원본의 실제 크기는 각각 1254×1254이며, 외부 CC0 팩에 포함된 파일로 분류하지 않고 이번 작업에서 CC0를 부여하지 않는다. [전체 생성 프롬프트·원본 반환 경로·크기](../Tools/WorldDev/GroundGeneration.json)

식생 배열 셰이더, 바람·접촉 흔들림 연결, LOD 프리팹과 지면/이끼 표현은 프로젝트 구현물이다. 이를 구매하지 않은 Quaternius Source판 셰이더로 표기하지 않는다.
