# 프로젝트 오르비스 — 기획서 2부: 오픈월드 & 탐사 설계

## 1. 이동 시스템

| 동작 | 설명 | 리소스 소모 |
|---|---|---|
| 걷기/달리기 | 기본 이동, 3초 이상 지속 달리기 시 스태미나 소모 | -2/초 |
| 등반 | 대부분의 절벽·벽면 등반 가능 | -8/초 |
| 활공(글라이더) | 고지대에서 낙하 대신 활공 | -5/초 |
| 수영 | 수면/수중 이동 | -6/초 |
| 대시/회피 | 전투 중 무적 프레임 포함 회피 | -15/회 |

- 스태미나 총량은 성장 재료로 영구 확장 가능
- 스태미나 0인 채로 등반 중이면 낙하 → 소량의 낙하 데미지

## 2. 필드 콘텐츠

- **원소 기믹 퍼즐**: 예) 화 원소 조각상을 순서대로 점화해 보물 개방. 지역마다 원소 연동 퍼즐 최소 5개 배치
- **도전의 방(사당형 던전)**: 소규모 전투/퍼즐 방, 클리어 시 강화 재료 지급. 지역당 8~12개
- **랜드마크 등반**: 지역 최고봉/거대 유적 정상 도달 시 전경 개방 + 패스트트래블 포인트 해금
- **필드 보스**: 지역별 1~2종, 주간 리젠. 원소 속성 약점 기믹 존재. 1차 확정 5종(지역당 1종) — 홍염각수(화/아그니아), 심해성룡(수/텔루나), 창공령조(풍/자피르), 지맥거신(암/그라니테), 천뢰익룡(뢰/볼트하임). 상세 스펙·전투 패턴·드랍은 `09_필드몬스터_보스_도감.md` 참고
- **필드 잡몹 — 원소 슬라임**: 5원소(화/수/풍/암/뢰) 공용 최하급 몹, 지역 무관 저레벨 구간에 배치되어 원소 반응 시스템 학습용으로 활용
- **필드 잡몹 — 무속성 공용 적(고블린 무리)**: 전 지역(숲/평원/산악/사막/설원/폐허/도시 주변)에 공통 출현하는 NEUTRAL 속성 도적 팩션, 지역 색과 무관한 범용 조우 콘텐츠
- **일일 위임 퀘스트**: NPC 부탁형 미니 퀘스트, 하루 3~5개, 소량 재화 보상
- **수집 요소**: 지역 특산 식물/광물, 등급별 보물상자(일반/정교/화려), 지역 도감(포토모드 연동)

## 3. 환경 시스템

- **낮/밤 사이클**: 실시간 24분 = 게임 내 24시간(예시 비율). 특정 몬스터/NPC는 야간 전용
- **날씨 (지역 원소와 연동)**
  - 비: 수 원소 필드 활성화 구간 확장, 화 원소 지속피해 약화
  - 뇌우: 뢰 원소 위험구역 생성(금속 무기 소지 시 리스크-리워드 기믹)
  - 강풍: 상승기류 지점 생성 → 활공 거리 증가
- **패스트트래블**: 지역별 웨이포인트 오벨리스크, 발견 즉시 해금

## 4. 지도 & UI 요소

- 미니맵 + 전체 지도(안개 해제 방식)
- 아이콘 필터(보물/퍼즐/도전의 방/자원)
- 지역별 탐사도(%) 트래킹 → 100% 달성 보상
