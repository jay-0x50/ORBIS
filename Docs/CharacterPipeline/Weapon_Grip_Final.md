# 여정의 검 — 최종 주인공 파지

2026-09-15. 아래는 staging 카탈로그에 저장한 최종 연결이다. 실제 프로젝트 전달 여부는 전달 검증 보고서로 확인한다.

공용 무기는 `Assets/Orbis/Game/LookDev/Resources/LookDev/WayfarerBlade.prefab`을 유지한다. Kenney Mini Dungeon CC0 블레이드와 기존 프로젝트의 골드 가드·청록 보석 장식이다. 이번 작업은 새 무기 다운로드가 아니라 두 원본 리그의 실제 손에 맞춘 소켓·손가락 보정이다. 오른손 본 이름과 기존 궤적 끝점 `(0, 0.94, 0)`은 유지했다.

| 캐릭터 | 최종 RightHand 위치 (m) | 회전 (Unity Euler 도) | 균일 스케일 |
|---|---|---|---:|
| 스텔라 | (-0.010210, 0.102929, -0.018426) | (16.6561, 17.9308, 274.2892) | 1.042689 |
| 폴라리스 | (0.007615, 0.092107, -0.025217) | (6.2021, 6.0689, 268.7546) | 1.040669 |

값의 원본은 각 최종 prefab 옆 `GripBinding.json`이며, 카탈로그 연결 증거는 `TestResults/CharacterPipeline/HeroFinalBinding/FinalHeroes01/Commit.json`이다. 최종 runtime 정규화 스케일을 다시 측정했으므로 초기 정적 Transfer 보고서의 socket scale을 그대로 복사하지 않는다. 두 검의 실제 월드 길이는 약 1.06m로 유지한다.

26개 모션 각각에서 오른손 손가락 20개 채널만 파지값으로 바꾸고 몸통·팔·다리의 원래 모션 곡선은 보존했다. 기존 공격 타격 시점과 무기 판정은 변경하지 않았다.

## 실제 확인

- 스텔라: Blender Grip04 → Unity Stella12Transfer01. 소켓·손가락 변환 후 원본 목표와의 최대 손 기준 본 오차 3.13mm, 피부 정점 오차 7.06mm. 이 값은 **전사 오차**이며 손잡이 관통 깊이가 아니다. Blender 원본 손 삼각형 교차 진단은 84개에서 3개로 줄었다.
- 폴라리스: Blender Grip03 → Unity Transfer03. 손 기준 최대 본 오차 6.50→3.48mm, 피부 정점 오차 18.95→8.36mm. 직접 포즈·Humanoid 왕복·보정 결과를 정면/위/손바닥에서 비교했다.
- 최종 runtime prefab으로 평지·공격 3타·G·Q·피격·이동 중 실제 Animator 재생을 확인했다. 12/24도 경사 및 긴 내리막 검수에도 같은 파지를 사용했다.

스텔라 엄지·검지와 폴라리스 새끼손가락에는 원본의 각진 장갑 형태와 약간의 간격이 남는다. 완전 무관통이나 모든 포즈에서 모든 손가락이 밀착한다고 표현하지 않는다. `Weapon_Grip_Review.md`는 초기 실패 후보까지 포함한 이전 기록이다.

## 직접 확인

`Assets/Scenes/Field.unity`를 열고 Play 후 저장된 주인공으로 시작한다. 마우스 왼쪽 버튼으로 3타, G로 원소 스킬, Q로 궁극기 연출을 확인한다. 오른손 소켓은 실제 카탈로그에 저장돼 있으므로 별도의 검수용 후보 교체 입력이 필요 없다. 다른 주인공 확인은 별도 테스트 프로필을 사용하며 실제 세이브 파일을 삭제하지 않는다.
