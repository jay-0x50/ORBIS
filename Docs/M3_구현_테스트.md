# 오르비스 M3 — 타격감·원소 이펙트

기획서 03의 「★ 타격감 & 이펙트 디자인 가이드」 전체를 M0~M2 게임플레이에 연결했다. Unity 6000.6.0f1, URP/Shader Graph/VFX Graph 17.6.0, Cinemachine/Timeline 6.6.0, Input System 1.20.0을 사용한다.

## 실행

1. Unity Hub에서 이 저장소 폴더를 열고 패키지·셰이더 임포트를 기다린다.
2. 메뉴 **Orbis > M3 > Setup and Validate**를 실행한다.
3. **Orbis > M3 > Open Effects Prototype**를 열고 Play. Game 뷰를 클릭해 커서를 잡는다.

세 씬 모두 완료된 게임플레이를 재사용한다. 기존 M0/M1/M2 씬은 각 마일스톤의 회귀 확인용으로 보존했다. M3의 실제 VFX를 확인하려면 아래 씬을 연다.

| 씬 | 용도 |
|---|---|
| `Assets/Orbis/M3/Scenes/M3_EffectsPrototype.unity` | 화·수·뢰·풍 파티, 증발/감전/과부하/확산 |
| `Assets/Orbis/M3/Scenes/M3_CrystallizeEffects.unity` | 4번 슬롯이 암 캐릭터, 결정화·보호막 |
| `Assets/Orbis/M3/Scenes/M3_ExplorationEffects.unity` | 기존 M2 절벽·활공·수영·필드 퍼즐·도전의 방에 M3 연출 연결 |

## 입력으로 확인

WASD 이동, Shift 달리기, Space 점프, 마우스 카메라, 왼쪽 클릭 기본공격. 숫자 1~4는 파티 전환. 공격 1·2타가 약 60% 진행됐을 때 다시 클릭하면 다음 타가 예약된다. 3타 적중에서 0.08초 히트스톱·강한 흔들림이 발생한다. 매 적중 시 원소 스파크, 무기 잔상, 튀어 오르는 HIT 카운터를 확인한다.

실험실 시작 위치에서 정면 주황색 더미가 공격 범위 안에 있다. 반응은 **앞 원소로 1회 적중 → 4초 안에 다음 캐릭터로 전환 → 1회 적중**으로 만든다. 각 조합 전에 F6으로 세 더미의 위치·원소 상태를 초기화한다.

| 반응 | 조작 순서 | 표시 |
|---|---|---|
| 증발 | 1 → 공격 → 2 → 공격 | 흰 수증기 폭발, 상승 입자, 짧고 약한 화면 밝기 증가 |
| 감전 | 2 → 공격 → 3 → 공격 | 보라 스파크. 이후 1초 간격 3회 실제 연쇄 피해를 받는 인접 더미 사이 전기 스플라인 |
| 과부하 | 1 → 공격 → 3 → 공격 | 폭발 링·방사형 입자·강한 Impulse, 기존 넉백 |
| 확산 | 1 → 공격 → 4 → 공격 | 화색 원형 충격파·퍼지는 입자·캐릭터 잔상 |
| 결정화 | 암 파티 씬에서 1 → 공격 → 4 → 공격 | 결정 파편, 시전자 주변 화색 보호막 |
| 풍+암 결정화 | 암 파티 씬에서 F9 → 4 → 공격 | 기존 확정 규칙대로 풍색 보호막 |

보호막은 실제 캐릭터의 실드 값에 연결된다. 다른 캐릭터로 바꾸면 해당 캐릭터의 실드 상태가 보이고, 원래 캐릭터로 돌아오면 남은 실드가 보인다. F7은 실험실에서 활성 캐릭터에게 수 피해를 주는 기존 테스트 입력이다.

**Q**는 사용자가 승인한 **궁극기 연출 전용 테스트**다. 각 슬롯을 선택한 뒤 Q를 눌러 모든 원소 팔레트를 확인한다. 피해·에너지 소비·새 스킬은 추가하지 않는다. 향후 실제 스킬에서 `M3Presentation.PlayUltimatePresentation()` 또는 `M3UltimateDirector.Play(element)`를 호출할 수 있다. 연출 중 Escape 또는 R로 취소하며, 포커스를 잃거나 컴포넌트가 비활성화돼도 입력·카메라·시간 설정을 복원한다.

| Timeline 시각 | 단계와 기본값 |
|---|---|
| 0.00초 | ① 캐릭터 클로즈업 컷인 0.3초 |
| 0.30초 | ② 0.4초간 20% 속도, 채도 +35 |
| 0.70초 | ③ 화면을 채우는 원소 입자·밝기 강조·실루엣, 0.25초 정지, Impulse 0.6 |
| 0.75초 | ④ 직접 합성한 임팩트 음향. 선택 항목인 캐릭터 음성은 미포함 |
| 0.95초 | ⑤ 정상 카메라 복귀, 현장에 원소 잔광 4초 |
| 1.05초 | Timeline 종료·입력 복원. 잔광은 별도로 수명을 마친 뒤 풀 반환 |

M2 연출 씬은 기존 F1~F5/F10 위치 이동, E 등반, 공중 Space 활공, 물 안 Ctrl 잠수·Space 상승, F 상호작용을 그대로 사용한다. 수영/활공 입력이나 퍼즐·방 조건을 바꾸지 않았다.

## 구현·조정 위치

- `M3Palette.cs`: 원소 주색/보조색을 기획서의 정확한 sRGB 헥스코드로 보관. GPU Vector4로 전달할 때만 선형 색으로 변환한다.
- `M3Feedback.cs`: 약/강/궁극기 Impulse 0.1/0.3/0.6. 강타 0.08초, 궁극기 0.25초. 여러 대상 동시 적중 시 정지 시간을 더하지 않고 남은 최댓값을 사용한다.
- `Resources/M3/Effects/*.vfx`: 편집 가능한 GPU 그래프 8개. 반응 5종은 서로 다른 방출·운동·마스크를 사용한다.
- `Resources/M3/Shaders/*.shadergraph`: 디졸브, 외곽선, 무기 트레일, 확산 링, 결정 실드 그래프 5개.
- `Resources/M3/Timeline/Ultimate.playable`: 5개의 Signal로 실제 연출을 구동. `PlayableDirector`는 UnscaledGameTime이므로 히트스톱 중에도 후속 단계를 진행한다.
- `M3VfxPool.cs`: 씬 진입 시 GPU 오브젝트 40개 준비(Impact 12개, 나머지 7종 각 4개). 가득 차면 같은 종류의 가장 오래된 항목을 재사용한다. 적중 때 Instantiate/Destroy하지 않는다.
- `M3MeshEffects.cs`: 링 8개, 체인 12개, 캐릭터 잔상 6개를 미리 준비한다. 무기 트레일·실드·외곽선도 재사용한다.
- `M3Presentation.cs`: M1 결과 이벤트를 VFX/음향에 연결. 실제 연쇄 대상만 알리도록 추가한 `ChainLinked`는 표시용 이벤트이며 피해 수치는 변경하지 않는다.
- `M3ProjectSetup.cs`: 그래프·Timeline 검증, 누락한 씬/원본 WAV 생성. 임포트된 자산을 포함해 전달하므로 플레이 중 생성 도구는 실행되지 않는다.

문서에 없는 수치(풀 용량, 입자 수명·속도·크기, 소리 길이·피치, 트레일 길이, 화면 밝기 등)는 구현 위치에 기본값 주석을 남겼다. GPU 입자와 시각적 풀 수명은 unscaled 시간, 원소 부착·피해·실드 수명은 기존 게임 시간 기준이다.

Shader Graph 편집 계약과 자산 출처는 [M3_Art_Assets.md](M3_Art_Assets.md), 전체 변경/생성 파일은 [M3_FILES.md](M3_FILES.md)를 참고한다.

## 자동 테스트

저장소 루트 PowerShell:

```powershell
.\Tools\Test-M3.ps1 -UnityPath 'C:\Program Files\Unity\Hub\Editor\6000.6.0f1\Editor\Unity.exe'
```

EditMode/PlayMode 전체를 실행해 M0~M2 회귀도 함께 검사한다. 결과 XML·로그는 `TestResults/M3-*.xml`, `M3-*.log`에 저장한다. GPU 검증은 그래프의 실제 살아 있는 입자 수를 검사하고 `M3_Impact.png` 등 8종 캡처를 남긴다.

`-Headless`를 주면 그래픽 장치가 없어 GPU 출력 테스트는 건너뛴다. 실제 이펙트 확인에는 일반 실행이 필요하다. 캡처는 카메라 렌더 결과이며 IMGUI 도움말/HIT 카운터는 포함하지 않는다.

## 검증 결과 — 2026-09-10

Unity 6000.6.0f1 / Windows / D3D12(NVIDIA GPU)에서 다음을 확인했다.

- Editor 자산 설정·검증 통과: VFX Graph 8개, Shader Graph 5개 실제 패스 컴파일, Timeline 5개 Signal.
- **EditMode 112/112, PlayMode 33/33 통과**, 실패·건너뜀 0. 기존 M0~M2의 121개 회귀 테스트를 포함한다.
- 실제 GPU 입자: Impact 32, Vaporize 74, ElectroCharged 102, Overload 141, Swirl 91, Crystallize 46, Burst 241, Residue 76 방출 확인. 비동기 입자 수 조회 전에 실제 카메라 렌더를 갱신한다.
- 보호막, 체인, 디졸브 잔상·트레일, 궁극기 컷인·폭발 등 총 13개 렌더 캡처를 확인했다. `TestResults/M3_*.png`에 포함한다.
- 정상 완료·Escape 취소·컴포넌트 비활성화·일시 정지된 Timeline 취소 후 시계/입력/카메라 복구와 다음 재생을 검사했다.
- 독립 실행 파일 빌드 및 기기별 성능 측정은 실행하지 않았다. 보이스/고유 캐릭터·무기 모델은 이번 연출 범위에 포함하지 않았다.
