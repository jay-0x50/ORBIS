# Quaternius CC0 출처 증빙

공식 페이지 응답과 다운로드에 동봉된 라이선스를 원본 그대로 보존한 자료입니다. 접근 시각(UTC), HTTP 상태, 원본 URL, 파일별 SHA-256은 `Quaternius_License_Evidence.json`에 기록했습니다.

| 자료 | 공식 원본 | 보존 파일 |
|---|---|---|
| Stylized Nature MegaKit 제품 페이지 | https://quaternius.com/packs/stylizednaturemegakit.html | `Quaternius_MegaKit_Official.html` |
| 제작자의 MegaKit itch 페이지 | https://quaternius.itch.io/stylized-nature-megakit | `Quaternius_MegaKit_Itch.html` |
| 무료 Standard ZIP 동봉 라이선스 | 위 itch 페이지의 무료 Standard 다운로드 | `Quaternius_MegaKit_License_Standard.txt` |
| Ultimate Stylized Nature 제품 페이지 | https://quaternius.com/packs/ultimatestylizednature.html | `Quaternius_UltimateStylizedNature_Official.html` |
| 공식 Drive 폴더 동봉 라이선스 | https://drive.google.com/drive/folders/1IV3bXHzkNvuNWFHPi4KPx-G4ghuxIuT- | `Quaternius_UltimateStylizedNature_License.txt` |

두 제품의 공식 페이지와 동봉 파일에 CC0가 명시되어 있습니다. MegaKit은 무료 Standard판만 확보했습니다. 유료 Pro/Source판은 다운로드하지 않았습니다.

Ultimate 팩의 동봉 `License.txt` 첫머리에는 다른 팩 이름인 `Ultimate Platformer Pack`이 적혀 있습니다. 이를 수정하지 않고 보존했습니다. 해당 Ultimate Stylized Nature 공식 제품 페이지에 별도로 명시된 CC0를 함께 확인해야 합니다.

## 스크린샷 상태

실제 스크린샷은 확보하지 못했습니다. 이번 확인에서 computer-use의 CUA `getState()`가 `{"apps":[],"browsers":[]}`를 반환하여 연결된 브라우저 또는 네이티브 화면이 없었습니다. 텍스트로 만든 이미지나 프리뷰 이미지를 라이선스 스크린샷으로 대체하지 않았습니다.

HTML은 서버 응답 바이트를 그대로 저장했으며 외부 CSS/이미지/스크립트는 묶지 않았습니다. 따라서 공식 페이지 원문 보존 자료이며 오프라인 시각 캡처는 아닙니다. 브라우저 연결이 가능해지면 위 공식 페이지의 CC0 표시를 실제 화면으로 추가 캡처할 수 있습니다.
