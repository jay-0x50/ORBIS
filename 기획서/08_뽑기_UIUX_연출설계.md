# 프로젝트 오르비스 — 기획서 8부: 뽑기 화면 UI/UX & 연출 설계

## 0. 개요
- 확보한 뽑기 시스템 UI 목업(전체 화면 레이아웃, 5성 등장 시퀀스)을 기반으로 작성
- 06번 문서(재화/뽑기/동료풀)의 수치·구조 설계를 실제 화면으로 구현하기 위한 레이아웃/연출 상세 문서
- 브랜드 비주얼(별자리·나침반 모티브)은 01번 문서 "비주얼 아이덴티티" 섹션 참고

## 1. 전체 화면 레이아웃

### 상단 헤더
- 좌측: 로고(별자리/나침반 아이콘) + "프로젝트 오르비스 PROJECT ORBIS"
- 중앙: 국문 태그라인 "별이 이끄는, 새로운 여정" / 보조카피 "세상의 끝에도, 아직 보지 못한 이야기가 있다."
- 우측: 영문 카피 "More Stars, Another Tomorrow." / "세계를 넘는 인연이 당신을 기다리고 있다."

### 좌측 사이드바 — 뽑기 재화
- 오르빗 결정 / 인연의 서약서(한정) / 표준 서약서(상시) / 루멘 — 4종 재화 아이콘 + 플레이버 텍스트 (상세는 06번 문서)
- 하단: 5원소 아이콘 목록(화·수·풍·암·뢰) + 카피 "FIVE ELEMENTS, A HIGHER WORLD" — 아이콘 컬러는 03번 문서 원소 컬러 팔레트와 통일 필요

### 중앙 — 배너 영역
- 배너 탭 3종:
  1. **한정 이벤트** — 기간제 픽업 배너 (예: "별을 가르는 물결 - 마리스 확률 UP!")
  2. **상시 뽑기** — "여정의 동행" (상시 배너 고정 명칭 제안)
  3. **기타** — "추억의 조각" (특수 목적 배너, 용도는 추후 확정 — 예: 초보자 전용/과거 한정 재판매)
- 배너 카드 구성: 배너 아트 + 배너 타이틀(2단 카피) + 픽업 기간 + UP! 캐릭터 정보(등급/이름/한줄카피) + 보유 재화 표시 + 1회/10회 뽑기 버튼
- 하단 버튼: 상세정보 / 뽑기기록 / 캐릭터체험

### 우측 — 5성 프리뷰 패널 ("5성 등장 연출 — 예고 자막 시스템")
- 카피: "별은 먼저 속삭이고, 그 후에 모습을 드러낸다."
- 현재 구현된 5성 5인 전원을 카드로 나열 (원소 아이콘 + 이름 + 별등급 + 무기/원소 태그 + 지역 수호자 타이틀 + 예고 대사 1줄)
- 하단 카피: "…그리고 마침내, 한 사람의 이름이 별빛 속에서 불려온다." / "A WORLD OF DESTINY"

## 2. 5성 등장 연출 시퀀스 (상세 스토리보드, 7단계)

*(표는 06번 문서에도 요약 게재됨 — 본 절이 연출팀용 상세본)*

| # | 단계명 | 화면 카피 | 연출 디테일 |
|---|---|---|---|
| 1 | 별이 멀어짐 | "하늘을 가르는 빛" | 유성이 화면을 가로지르는 트레일 연출 |
| 2 | 빛의 색이 변함 | "황금빛으로 물드는 별" | 등급 색상으로 별빛 색 전환 (3성 블루 / 4성 퍼플 / 5성 골드) |
| 3 | 운명의 나침반 | "별이 당신을 향해 멈춘다" | 나침반/별자리 문양이 화면 중앙에 형성되며 정지 |
| 4 | 이름의 페이지 | "운명이 새겨진 한 장이 펼쳐진다" | 책/카드 형태의 페이지가 펼쳐지는 연출 |
| 5 | 실루엣 | "그 이름이, 드디어" | 캐릭터 실루엣이 빛 속에서 드러남 |
| 6 | 이름의 선언 | 캐릭터 고유 대사 + 이름 텍스트 | 실루엣 유지 상태로 예고 대사 노출 → 이름 공개 |
| 7 | 등장 | "당신의 여정에, 새로운 빛이" | 정식 일러스트 풀 리빌 + 등급/이름/원소 아이콘 + SKIP 버튼 노출 |

- 전체 슬로건: "별이 가리키는 이름, 마침내 당신에게." / "Across the countless worlds, at last, with you."
- 마무리 카피: "수많은 세계 속에서도, 언젠가 당신과." / "A NEW STAR RISES."
- "연출 스킵" 체크박스 상시 제공 — 반복 뽑기 시 6~7단계로 즉시 스킵

## 3. 결과 화면

- **5성 획득 시**: 캐릭터 아트 + "NEW" 배지(신규 획득 시) + 이름/별등급 + 등장 대사 + 하단 카피 "당신의 여정에, 새로운 인연이 찾아왔습니다."
- **10연차 결과 요약**: 획득한 캐릭터 전원을 카드형으로 나열 (원소 아이콘 + 이름 + 별등급), 5성은 카드 강조 처리

## 4. 공통 UI 요소

- 체크박스: 연출 스킵
- 보조 버튼: `?`(도움말) / `!`(공지·주의사항)
- 안내 캐릭터 챗버블: 코스모(조력자, 07번 문서) 등장 — 예시 멘트 "오늘도, 좋은 인연이 당신을 기다리고 있어요."
- 공통 액션 버튼: [1회 뽑기] [10회 뽑기] / [상세정보] [뽑기기록] [캐릭터체험] / [취소] [확인]
- 하단 카피: "PROJECT ORBIS — FOR A BRIGHTER TOMORROW"

## 5. 후속 확정 필요 사항

- [ ] 5성 등장 대사 최종안 확정 — 06번 문서에 "지역 수호자" 톤과 "개인 신념" 톤 2가지 버전이 혼재. 시나리오팀 확정 필요
- [ ] "기타(추억의 조각)" 배너의 실제 용도 정의 (초보자 전용? 과거 한정 재판매? 기타 재화 교환?)
- [ ] 3성/4성 등장 연출 상세 스토리보드 (현재는 5성만 상세 설계됨)
- [ ] 코스모 챗버블 멘트 풀(3~5개 로테이션) 추가 작성
