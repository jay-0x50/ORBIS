# 편집 가능한 오픈월드 게임 씬

게임 씬은 `Assets/Orbis/Game/Scenes/Orbis_OpenWorld.unity`입니다. Unity 메뉴 **Orbis > Game > Open Open World**로 엽니다. Play를 누르기 전부터 Hierarchy와 Scene 뷰에서 아그니아의 지형, 호수, 절벽, 길, 수입 프롭, 퍼즐, 도전방, NPC, 보스를 확인하고 편집할 수 있습니다.

기존 마일스톤 씬은 실행 시 생성하는 검증용 구성을 유지합니다. 새 게임 씬은 환경과 콘텐츠 오브젝트를 씬 파일에 저장하며, 플레이 시작 시 같은 오브젝트에 기존 게임 로직을 연결합니다. 편집 모드 전용 모형을 숨기고 월드를 다시 생성하는 방식이 아닙니다.

## 저장된 월드 구성

기존 M2 아그니아의 **60 × 55m** 이동 공간과 상호작용 좌표를 재사용합니다. 검증한 씬에는 리그·아웃라인을 포함한 오브젝트 820개, Renderer 453개, Collider 24개가 저장되어 있습니다.

| Hierarchy 그룹 | 배치 |
| --- | --- |
| 01 Terrain and Traversal | 지면, 호수와 경사 해안, 8m 등반 절벽, 능선, 길, 나무·바위·선착장 |
| 02 Field Puzzle | 원소 석상 I~III, 보상 상자 |
| 03 Challenge Courtyard | 도전방 벽·입구·표적 3개 |
| 04 Guardian Arena | 필드보스와 약점 코어, 전투 공간 |
| 05 Settlement and Transit | 주인공 시작점, NPC·게시판·캠프·감시탑·지역 이동 표식 |
| 06 Lighting and View | 태양광, 선택 전 전경 카메라 |
## 실행

1. Unity 6000.6.0f1로 프로젝트를 열고 **Orbis > Game > Open Open World**를 선택합니다.
2. Hierarchy에서 지형·건물·콘텐츠 그룹을 펼칩니다. 오브젝트 선택 후 **F**로 Scene 뷰를 해당 오브젝트에 맞출 수 있습니다. 여기서 F는 에디터 조작이며 게임 상호작용 키와 별개입니다.
3. **Play**합니다. 이미 주인공을 선택한 저장은 즉시 시작합니다. 미선택 저장은 월드를 배경으로 스텔라/폴라리스 선택 → 확정 → 여정 시작을 진행합니다.
4. 기존 M1.6 선택 씬으로 시작해도 선택 후 새 게임 씬에 진입합니다. 가챠 로스터·주인공 선택 규칙과 기존 저장은 유지됩니다.

| 입력 | 확인할 동작 |
| --- | --- |
| WASD / Shift / Space | 이동 / 달리기 / 점프 |
| 마우스 | 3인칭 카메라 |
| E / 공중 Space | 절벽 등반 / 활공 |
| 물속 Ctrl / Space | 잠수 / 상승 |
| 1~4 | 파티 전환, 주인공은 1번 고정 |
| Tab / G | 주인공 원소 전환 / 공통 원소 스킬 |
| 좌클릭 / Q | 일반공격 / 기존 궁극기 연출 |
| F | NPC, 상자, 도전방 상호작용 |
| F1~F6 | 시작점 / 퍼즐 / 도전방 / 보스 / NPC / 조사 표식으로 테스트 이동 |
| F10, ↑↓, Enter | 기존 다른 지역 이동, 아그니아를 선택하면 이 게임 씬으로 복귀 |

주인공 기본공격은 물리이므로 불 석상 I→II→III는 **Tab으로 화 선택 후 G**로 순서대로 적중시킵니다. 도전방에서는 **F**로 시작하고 수 부착 후 화 스킬로 증발 반응을 만듭니다. 보스 약점·보상·위임은 기존 아그니아 규칙을 사용합니다.

## 씬 편집

지형의 Collider, WaterVolume, ClimbableSurface와 수입 프롭은 씬에 저장된 실제 오브젝트입니다. Play 전 위치·크기·재질을 편집하고 저장하면 게임에서도 해당 배치를 사용합니다. 퍼즐 석상 배열의 순서가 I→II→III이며, 상호작용 위치는 `M4AuthoredRegion`에 연결된 마커/액터에서 읽습니다. 필수 참조를 삭제하면 검증이 누락 연결을 알립니다.

플레이어, Cinemachine 카메라, 파티·반응 매니저와 이펙트 풀은 주인공 선택 이후 기존 시스템이 생성합니다. Scene 뷰의 Spawn 마커는 실제 시작 위치이고, Overview 카메라는 선택 전 월드 전경을 보여줍니다. 게임 시작 후 Overview 카메라는 꺼집니다.

생성 메뉴는 기존 게임 씬을 덮어쓰지 않습니다. **Create Open World**는 씬이 없을 때만 생성하며, 이미 있으면 검증합니다. 직접 편집한 씬은 보존됩니다. 저장 경로와 주인공 규칙은 [M1.6 문서](M16_구현_테스트.md)를 참고하세요.

## 검증

Unity 6000.6.0f1에서 씬 생성·저장·다시 열기 참조 검증을 완료했고, 전체 테스트 **343개**가 통과했습니다. **EditMode 288/288, PlayMode 55/55**, 실패·건너뜀 0개입니다. 새 게임 씬 테스트 5개는 같은 씬에서 주인공 선택, 실배치 참조·충돌체 편집 유지, 초기화 중복 방지, 등반·수영, 퍼즐·도전·보스 연결, 다른 지역 왕복을 검증합니다. 평상시 활공 모델이 숨겨지는 것도 확인했습니다. 자동 테스트는 임시 저장만 사용합니다.

결과: `TestResults/Game-Setup.log`, `Game-Presentation.log`, `Game-EditMode.xml/.log`, `Game-PlayMode.xml/.log`. 실제 Unity 렌더 캡처는 `TestResults/Game_Overview.png`, `Game_Player.png`입니다. 플레이어 캡처에는 기존 등장 이펙트가 잠시 표시될 수 있습니다.

재실행: Unity Test Runner에서 EditMode / PlayMode 각각 Run All. 게임 씬만 검증하려면 PlayMode의 `Orbis.Game.Tests.AuthoredGameSceneTests`를 실행합니다.
