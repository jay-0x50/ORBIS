## 2. 스타일 통일 전략

여러 소스에서 가져온 애셋은 스타일이 제각각이라 아래 방식으로 통일감을 만든다.

1. **공통 툰쉐이더 강제 적용**: 모든 캐릭터·환경 머티리얼에 동일 툰쉐이더 + 아웃라인 두께 적용
2. **컬러 팔레트 통일**: 환경 텍스처는 포스트프로세싱(컬러 그레이딩)으로 톤 맞추기
3. **비율 통일**: 캐릭터 헤드-투-바디 비율을 기준치로 리스케일 (SD 캐릭터 vs 실사 비율 혼용 방지)

## 3. 라이선스 체크리스트 (배포 전 필수 확인)

- [ ] CC0 애셋: 자유 사용, 출처 표기 불필요 (크레딧 문서는 유지 권장)
- [ ] CC-BY / CC-BY-SA 애셋: 크레딧 목록에 반드시 명시
- [ ] Mixamo 애셋: 게임 내 사용 가능, 애셋 자체 재판매·재배포는 금지
- [ ] itch.io 개인 라이선스 애셋: 상업적 사용 가능 여부 팩별 재확인 (일부는 개인 프로젝트 한정)
- [ ] 모든 애셋의 원본 다운로드 링크 + 라이선스 스크린샷을 프로젝트 문서에 아카이빙
