# 오르비스 M4 — 지역 확장·주간 보스·일일 위임

M1.6 이후 현재 저장 버전은 **3**이며, 주인공 선택·원소를 추가했습니다. 기존 재화·피티·월드 진행은 보존됩니다. 새 게임 시작은 [M1.6 선택 화면](M16_구현_테스트.md)을 사용하세요.

M1.5 통합 이후 이 문서의 기존 코인은 **루멘**으로 표시되며, 동일 JSON 저장의 v2 재화 항목으로 이전됩니다. 최신 저장 구조와 재화 시연은 [M1.5 문서](M15_구현_테스트.md)를 참고하세요.

M2의 아그니아에 지역 보스를 연결하고 텔루나·자피르·그라니테·볼트하임 그레이박스를 추가했다. 각 지역의 원소 퍼즐, 반응 도전방, NPC 위임, 필드 보스를 기존 이동·파티·원소 반응·M3 연출과 연결한다. Unity 6000.6.0f1, URP 17.6.0, Cinemachine 6.6.0, Input System 1.20.0, Addressables 2.11.2를 사용한다.

보스 약점·노출 방식과 리셋 시각 등 기획서에 없는 정책은 답변 대기 중 고지한 **권장 기본값**을 적용했다. 사용자 확정 설정으로 간주하지 않는다.

## 실행과 지역 이동

1. Unity Hub에서 프로젝트를 열고 패키지 임포트를 기다린다.
2. **Orbis > M4 > Setup and Validate**를 실행한다.
3. **Orbis > M4 > Open Launcher**로 Assets/Orbis/M4/Scenes/M4_Launcher.unity를 연다.
4. Play를 누르면 Addressables로 아그니아가 열린다. Game 뷰를 클릭해 입력을 잡는다.
5. **F10**을 누른 뒤 **↑/↓**로 목적지를 선택하고 **Enter**로 이동한다. **Esc**는 메뉴 취소다. 지역 입구 오벨리스크 근처에서 **F**를 눌러도 같은 메뉴를 연다.

지역 씬은 Assets/Orbis/M4/Scenes/ 아래 M4_Agnia.unity, M4_Teluna.unity, M4_Zephyr.unity, M4_Granite.unity, M4_Voltheim.unity다. **Orbis > M4 > Open [지역]**으로 개별 씬을 바로 열어 시험할 수도 있다. 실제 지역 간 로딩은 Launcher/F10 경로로 확인한다.

한 번에 한 지역을 Single 모드로 로드한다. 이동 시 현재 HP·스태미나를 유지하며 같은 원소 캐릭터가 목적지 파티에 있으면 선택도 유지한다. 목적지 파티에 없는 원소는 기본 슬롯으로 진입한다. 전투 도중 떠난 보스는 재진입 시 초기 상태가 되며 저장된 주간 처치 기록이 있으면 처치 상태를 유지한다. 위치와 전투 중 보스 HP를 JSON에 저장하지 않는다.

Editor는 Addressables의 **Use Asset Database** 모드로 실행한다. 플레이어용 로컬 번들은 **Orbis > M4 > Build Local Addressable Content**로 만든다. 지역마다 별도 번들이며 원격 서버/CDN은 사용하지 않는다. Launcher가 첫 기본 빌드 씬이고 지역 씬은 Addressables에만 포함한다. 이 메뉴는 지역 콘텐츠 번들 빌드이며 독립 실행 파일 생성은 별도다.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD / 마우스 | 이동 / 카메라 |
| Shift / Space | 달리기 / 점프 |
| E | 등반 가능한 벽 잡기·놓기 |
| 공중 Space | 활공 시작·해제 |
| 물속 Space / Ctrl | 상승 / 잠수 |
| 왼쪽 클릭 / 1~4 | 기본공격 콤보 / 파티 전환 |
| Q / 연출 중 Esc 또는 R | 기존 M3 궁극기 연출 시험 / 취소 |
| F | NPC·상자·도전 입구·오벨리스크 상호작용 |
| F1 / F2 / F3 | 시작 지점 / 퍼즐 / 도전 입구로 시험 이동 |
| F4 / F5 / F6 | 보스 근처 / NPC 근처 / 조사 표식으로 시험 이동 |
| F10 / ↑↓ / Enter | 지역 선택 메뉴 / 선택 / 이동 |
| R | 현재 전투·퍼즐·도전 연습 초기화, 입구 복귀 |

F 상호작용은 대상에서 2.5m 안에서 사용한다. F2/F4는 대상 근처로 이동시키므로 실제 공격 거리에 들어가 표적을 바라보고 공격한다. Q는 연출 시험이며 신규 스킬 피해나 에너지 소비를 추가하지 않는다.

R은 HP·스태미나와 연습 상태를 초기화하지만 **위임·코인·주간 보스 처치 기록은 유지**한다. 이미 보상을 받은 상자/도전의 강화 재료도 같은 세션에서 중복 지급하지 않는다.

## 지역별 파티와 목표

각 지역 퍼즐은 표식 **I → II → III**에 해당 지역 원소로 직접 공격한다. 이미 켜진 석상의 같은 원소 재적중은 무시하고 잘못된 순서/원소는 진행을 초기화한다. 도전은 입구 F로 시작해 **60초 안에 표적 3개에 지정 반응**을 발생시키는 방식이다.

| 지역 | 슬롯 1 / 2 / 3 / 4 | 퍼즐 원소 | 도전 반응·예시 | 보스 약점 |
| --- | --- | --- | --- | --- |
| 아그니아 고원 | 화 / 수 / 뢰 / 풍 | 화(1) | 증발: 1 공격 → 2 공격 | 수(2) |
| 텔루나 군도 | 화 / 수 / 뢰 / 풍 | 수(2) | 감전: 2 공격 → 3 공격 | 뢰(3) |
| 자피르 초원 | 화 / 수 / 풍 / 암 | 풍(3) | 확산: 1 공격 → 3 공격 | 암(4) |
| 그라니테 산맥 | 화 / 수 / 뢰 / 암 | 암(4) | 결정화: 1 공격 → 4 공격 | 화(1) |
| 볼트하임 | 화 / 수 / 뢰 / 풍 | 뢰(3) | 과부하: 1 공격 → 3 공격 | 수(2) |

캐릭터는 기존 Ignis(화), Maris(수), Sparkle(뢰), Aura(풍), Grom(암)를 사용한다. 반응 예시는 같은 표적에 첫 원소를 붙이고 4초 안에 두 번째 슬롯으로 바꾸어 적중시키는 순서다.

퍼즐 상자 F는 강화 재료 5개, 도전 완료 후 입구 F는 강화 재료 3개를 지급한다. 이미 수령한 뒤 다시 F를 누르면 연습 재시작 경로를 사용할 수 있다. 강화 재료는 기존 M2의 세션 인벤토리이고 M4의 JSON 코인과 별개다.

아그니아는 기존 절벽·물·필드 배치를 재사용한다. 텔루나는 섬·도보다리·바다·해안 경사, 자피르는 초원·풍차·활공 절벽, 그라니테는 높이 4/8/12m의 광산 지형과 경사로, 볼트하임은 전도 탑·도시 가로·뇌운 실루엣이 있는 그레이박스다. 새로운 길과 지형은 탐사·전투 동선을 검증하는 배치다.

## 보스와 공유 HP

권장 기본 정책은 **약점 원소 직접 적중 3회 → 4초 코어 노출 → 피해 2배**다. 세 번째 약점 적중부터 배율이 적용된다. 코어는 약점 색으로 표시되고 노출 시 흰색이 된다. 보스 고유 원소는 정체성/공격 속성이며 매 프레임 원소 오라를 자동 재부착하지 않는다. 약점 노출 규칙은 기존 M1 반응표와 별개다.

| 지역 | 보스 HP | 공격 예고 | 공격 후 회복 | 범위 반경 | 기본 공격 피해 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 아그니아 | 320 | 1.0초 | 2.5초 | 3.0m | 12 |
| 텔루나 | 300 | 1.2초 | 2.6초 | 3.4m | 11 |
| 자피르 | 300 | 0.8초 | 2.1초 | 2.8m | 10 |
| 그라니테 | 400 | 1.3초 | 3.0초 | 3.2m | 16 |
| 볼트하임 | 340 | 0.9초 | 2.2초 | 3.0m | 13 |

위 수치는 모두 기획서에 없는 프로토타입 기본값이다. 보스는 6m 안에서 교전을 시작하고 8m 밖이나 높이 차 4m 이상이면 교전을 초기화한다. 예고 링 밖으로 이동하거나 지형으로 가려 범위 공격을 피할 수 있다. 실제 HP 감소는 기존 원소 반응·실드 흡수 뒤의 피해를 따른다.

파티는 기본 HP 100을 공유하며 전환으로 회복되지 않는다. HP가 0이 되면 진행 중 반응 처리가 끝난 뒤 입구로 구조되고 HP·스태미나·현재 전투를 초기화한다. 완료된 위임과 코인, 주간 처치 기록은 유지한다.

지역 보스 최초 주간 처치는 코인 50을 지급한다. 같은 지역의 같은 주 처치 기록에는 중복 보상이 없으며 재시작·지역 재진입·R로 보스를 다시 생성하지 않는다. 주간 경계를 넘으면 다시 도전할 수 있다.

## NPC 위임과 저장

모든 지역 NPC는 같은 게시판을 공유한다. 매일 **20개 정의(5지역 × 조사/퍼즐/도전/보스 4종)**에서 4개를 제공한다. 종류별 1개씩 서로 다른 4지역에 배치하며 5일 동안 전체 정의를 순환한다.

1. F5로 NPC 근처에 이동하고 F로 오늘의 Offered 위임을 수락한다.
2. 오른쪽 목록의 지역으로 이동해 Accepted 목표를 수행한다. 조사 목표는 F6 또는 조사 표식 2m 안으로 들어가면 된다.
3. Completed 상태가 되면 아무 지역 NPC에게 돌아가 F로 코인 25를 수령한다. Claimed 위임은 재수령할 수 없다.

조사·퍼즐·도전은 수락한 뒤 수행해야 한다. 퍼즐/도전을 먼저 끝냈다면 연습을 초기화한 뒤 다시 완료한다. **보스 위임은 이번 주 격퇴 기록을 확인하는 예외**다. 이미 그 지역 보스를 이번 주에 처치했다면 위임 수락 시 즉시 Completed가 되므로 NPC에서 다시 F로 보상을 받을 수 있다. 수락 후 처치했다면 보스 코인·주간 기록·위임 완료를 같은 저장 작업으로 확정한다.

기획서에 없는 리셋 시각의 권장 기본값은 **일일 KST 04:00, 주간 월요일 KST 04:00**이다. 일일 경계에서는 수락/완료/수령 상태를 새 위임으로 바꾸되 코인은 유지한다. 주간 경계에서 지역 보스 처치 기록을 비운다. 저장한 최대 UTC 시각보다 시스템 시간이 뒤로 가면 이전 날짜로 되돌아가 위임이나 보상을 다시 열지 않는다. 서버 시각 검증은 추가하지 않았다.

저장 위치는 Application.persistentDataPath/Orbis/m4-progress.json이다. 현재 프로젝트의 Windows 설정에서는 아래 경로다.

    %USERPROFILE%\AppData\LocalLow\Orbis\Orbis M0\Orbis\m4-progress.json

JSON에는 버전, 리셋 설정, UTC 고수위 시각, 일일/주간 기간, 위임 ID·상태, 주간 보스 기록, 코인과 처리한 목표 이벤트 ID를 저장한다. HP·스태미나·선택 캐릭터는 현재 실행 중 지역 이동에서만 전달하고 M2 강화 재료는 세션 기록으로 유지한다.

저장은 임시 파일에 쓴 뒤 본문을 교체하고 직전 정상 파일을 .bak으로 보존한다. 본문이 손상되면 정상 백업을 시도한다. 복구 후 다음 저장에서는 손상된 본문을 .corrupt-* 파일로 보존한다. 본문/백업 모두 유효하지 않거나 미래 버전이면 원본을 유지하고 저장을 잠근 상태와 메시지를 표시한다. 쓰기에 실패하면 해당 상태·코인 변경도 메모리에서 취소하며 HUD에 오류를 표시한다.

날짜/주간 경계 시험은 주입 시계를 쓰는 EditMode 테스트로 재현한다. 실제 사용자 저장 파일이나 운영체제 시계를 수정할 필요가 없다.

## 수동 확인 순서

1. **지역 로딩:** Launcher에서 시작해 F10으로 다섯 지역을 한 번씩 이동한다. 지역 이름·슬롯·지형이 바뀌고 입력이 복구되는지 확인한다. HP/스태미나를 일부 사용한 후 이동해 공유 값이 유지되는지도 확인한다.
2. **의뢰:** NPC F로 수락 후 대상 지역으로 이동한다. 조사 위임은 F6으로 완료하고 NPC F로 25코인을 수령한다. 다시 F를 눌러도 코인이 늘지 않는지 확인한다.
3. **퍼즐:** 해당 지역에서 F2, 지정 원소 선택, I→II→III 직접 적중 후 상자 F. 오답 초기화, 강화 재료 첫 지급, 재연습 시 중복 지급 방지를 확인한다.
4. **도전:** F3 후 F로 시작한다. 표의 조합을 각 표적에 적용하고 완료 후 입구 F로 보상을 받는다. 제한 시간 초과 시 Failed와 표적 비활성화, 입구 F 재도전을 확인한다.
5. **보스:** F4 후 공격 거리로 접근한다. 약점 속성 3회 직접 적중으로 Exposed·흰 코어·추가 피해를 확인하고 링 밖으로 피하기/실드 흡수/공유 HP 감소를 확인한다. 처치 후 50코인, R·재진입·프로젝트 재실행 후 주간 처치 유지를 확인한다.
6. **보스 증명:** 이미 처치한 지역의 보스 위임이 제공되는 날에 수락하면 즉시 Completed가 되는지 확인한다. 날짜 조합은 자동 테스트의 주입 시계로도 재현한다.
7. **구조·연출:** 보스에게 공격받아 HP 0 구조를 확인한다. Q 정상 종료와 Esc/R 취소 후 입력·카메라·시간이 돌아오고 위임/코인이 유지되는지 확인한다.
8. **저장:** 수락 또는 수령 후 Play를 종료하고 다시 실행한다. 동일 날짜의 위임 상태·코인·주간 처치가 복원되는지 확인한다. 손상 복구/쓰기 실패는 실제 사용자 파일 대신 자동 테스트의 임시 폴더에서 검증한다.

## 자동 검증

Unity Editor에서 프로젝트를 닫은 뒤 저장소 루트 PowerShell에서 실행한다.

    .\Tools\Validate-M4.ps1 -UnityPath 'C:\Program Files\Unity\Hub\Editor\6000.6.0f1\Editor\Unity.exe'

기본 실행은 M4 설정 검증, 로컬 Addressables 콘텐츠 빌드, **전체 EditMode/PlayMode**를 순서대로 실행한다. M0~M3 회귀도 포함한다. 결과는 TestResults/M4-setup.log, M4-EditMode.xml/.log, M4-PlayMode.xml/.log에 남긴다. 스크립트는 이번 실행에서 새 XML이 생성되었는지, 테스트가 실제 실행되었는지, 실패가 없는지 확인한다.

-SkipContentBuild는 설정 및 Editor 기반 테스트만 실행한다. 이 경우 플레이어용 번들은 검증하지 않는다. -Headless는 그래픽 장치를 사용하지 않으므로 GPU 출력 검증을 건너뛸 수 있다. 전체 연출 확인에는 기본 그래픽 실행을 사용한다. 독립 실행 파일 빌드는 이 스크립트 범위에 포함하지 않는다.
