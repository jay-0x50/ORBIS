# 프로젝트 오르비스 — 기획서 3부: 전투 & 스킬 이펙트 설계

## 1. 파티 & 스위칭 시스템

- 파티 구성: 최대 4명, 필드에서 즉시 전환(단축키 1~4)
- 스위칭 쿨다운: 없음. 단, 직전 캐릭터가 원소 폭발을 사용한 직후 1초 딜레이
- 스위칭 시 이전 캐릭터가 부착한 원소가 필드에 3~5초 유지되어 다음 캐릭터와 반응 가능

## 2. 원소 & 반응 시스템

### 5원소
화(火) · 수(水) · 풍(風) · 암(岩) · 뢰(雷)

### 원소 반응표

| 조합 | 반응명 | 효과 |
|---|---|---|
| 화 + 수 | 증발 | 데미지 1.5~2배 증폭 |
| 뢰 + 수 | 감전 | 지속 데미지 + 주변 적에게 전기 연쇄 |
| 화 + 뢰 | 과부하 | 소규모 폭발 + 넉백 |
| 풍 + 임의 원소 | 확산 | 부착 원소를 주변으로 넓게 퍼뜨림(광역화) |
| 암 + 임의 원소 | 결정화 | 해당 원소 속성 보호막 생성(캐릭터 장착 가능) |

*(추후 빙/초 등 원소 추가 시 반응표를 확장할 수 있는 구조로 설계)*

## 3. 스킬 슬롯 구조 (캐릭터 1인당)

| 슬롯 | 설명 | 쿨다운 |
|---|---|---|
| 기본 공격 | 3~4단 콤보, 원소 속성 소량 부착 | 없음(선딜만 존재) |
| 원소 스킬 | 즉발형 서브 스킬, 원소 강하게 부착 | 6~12초 |
| 원소 폭발(궁극기) | 게이지 충전형, 화면 전체 영향 | 게이지 100% 충전 시 |

- 원소 폭발 게이지는 기본공격/피격/원소스킬 사용 시 축적
- 파티원 전원이 게이지를 개별 보유(스위칭 후에도 유지)

## 4. ★ 타격감 & 이펙트 디자인 가이드

"보는 맛"의 핵심 파트. 모든 스킬 VFX 제작 시 아래 기준을 공통 적용한다.

### 원소별 컬러 팔레트 (고정)

| 수 | #1FA2FF | #A7E8FF |
| 풍 | #6CFFB8 | #E8FFF3 |

### 히트감 3요소
1. **히트스톱**: 강타격 시 0.05~0.1초, 궁극기 시전 시 0.2~0.3초 프레임 정지
2. **스크린쉐이크**: Cinemachine Impulse로 타격 강도 비례 진동 (약공격 0.1 / 강공격 0.3 / 궁극기 0.6)
3. **임팩트 파티클**: 타격 지점마다 원소 컬러 스파크 + 콤보 카운터 UI 팝업 애니메이션

### 궁극기(원소 폭발) 연출 시퀀스
1. 카메라 컷인(캐릭터 클로즈업, 0.3초)
2. 짧은 타임슬로우(0.3~0.5초) + 화면 채도 강조
3. 풀스크린 원소 파티클 버스트 + 캐릭터 실루엣 하이라이트
4. 보이스라인(선택) + 사운드 임팩트
5. 정상 시점 복귀, 필드에 원소 잔여 이펙트 3~5초 유지

### 원소 반응별 이펙트 디테일
- **증발**: 수증기 폭발 + 화이트아웃 살짝 + 상승 파티클
- **감전**: 캐릭터 간 전기 체인 라인(스플라인 렌더러) + 스파크
- **과부하**: 폭발 링 + 넉백 파티클 + 강한 스크린쉐이크
- **확산**: 원형 충격파(링 셰이더) + 원소 컬러로 물드는 잔상
- **결정화**: 크리스탈 파편 비산 + 캐릭터 주변 보호막 셰이더

### 기술 구현 스택
- 파티클: **Unity VFX Graph** (GPU 파티클, 대규모 이펙트에 적합)
- 셰이더: **Shader Graph** — 디졸브(소환/소멸), 아웃라인(캐릭터 강조), 트레일(무기 궤적)
- 카메라 연출: **Cinemachine** (Impulse + 가상카메라 전환)
- 컷씬형 연출: **Timeline** (궁극기 연출 시퀀스 제작)
- 최적화: 파티클 **오브젝트 풀링** 필수 (런타임 Instantiate/Destroy 지양)
